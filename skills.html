superhuman/Skills

Plugin, commands and skill. One workflow for Claude Code and Codex.

superhuman ships as a Claude Code plugin with seven slash commands and an agent team, and as a single skill for OpenAI Codex. Both run the same contracts. It builds on two other plugins: superpowers for planning and building, and everything-claude-code for language reviewers.

What you install

RuntimeWhat loadsHow you use it
Claude CodeThe plugin in .claude-plugin/: seven slash commands, an orchestrator and ten specialist subagents.Type a slash command, such as /contribute.
OpenAI CodexOne skill, skills/superhuman/SKILL.md, that runs the same agent contracts inline.Tell Codex: “use the superhuman skill to contribute.”

Claude Code

curl -fsSL https://raw.githubusercontent.com/gaurav0107/superhuman/main/install.sh | bash

Then restart Claude Code, or run /reload-plugins. The installer adds superhuman and the superpowers plugin it requires, and everything-claude-code unless you pass --skip-ecc. Read install.sh first, or run it with --dry-run.

OpenAI Codex

curl -fsSL https://raw.githubusercontent.com/gaurav0107/superhuman/main/install.sh | bash -s -- --codex

This also links the skill into ~/.codex/skills. You need gh (authenticated), git, jq and python3.

The slash commands

CommandWhat it does
/preferencesSets what /repo-finder looks for: languages, topics, a star floor and notes in your own words. --show prints the GitHub queries they compile to.
/repo-finderBuilds a ranked shortlist of repositories and the best open issue in each. /repo-finder 10 --lang rust --topic cli overrides the filters for one run.
/contributeOne full contribution, from issue to pull request. Aim it with /contribute owner/repo or /contribute owner/repo 12345.
/contribute-loopSeveral contributions one after another (3 by default, up to 20). Stops early on a safety halt or a crash.
/contribution-fleetSeveral contributions in parallel across different repositories, each with its own state directory, clone and lock.
/contribution-dashboardA report of the active run, its score history, plateaued dimensions and recent merge outcomes.
/contribution-sweepRecords which pull requests were merged or closed, and lists the open ones that need you: changes requested, a merge conflict, failing CI.

The skills it builds on

Agent Skills are folders of instructions and scripts, built around a SKILL.md file, that an agent loads when a task calls for them. Claude Code supports them natively; see Anthropic's skills documentation. superhuman uses skills from two plugins rather than reimplementing them:

PluginSkills usedRequired?
superpowerswriting-plans (the planner) and subagent-driven-development (the builder).Required
everything-claude-codeSpecialist reviewers for Python, Go, TypeScript, Java, Kotlin, Rust, C++, C#, Flutter and security.Recommended; falls back to inline prompts

The agents behind the commands

Each command runs the orchestrator, which runs specialist subagents in order: repo-finder, issue-selector, repo-profiler, planner, builder, impact-auditor, merge-probability-scorer, reviewer-dispatcher, resolve-comments and lesson-distiller. What each one does is on the agents page.

Telemetry

superhuman sends opt-out usage telemetry: three small events keyed by your GitHub username, and nothing about your repositories or code. What is sent, and how to turn it off.

Questions

Is superhuman a Claude Code plugin or a skill?

Both, depending on where you run it. In Claude Code it is a plugin with slash commands and subagents. In OpenAI Codex it is one skill that runs the same workflow inline.

Which Claude Code version do I need?

A Claude Code version with plugin support. After installing, restart Claude Code or run /reload-plugins so the commands appear.

Does it work without everything-claude-code?

Yes. The specialist reviewers come from that plugin; without it, the reviewer dispatcher uses a built-in inline review prompt. Install with --skip-ecc to leave it out.

Is it free?

superhuman is free and open source under the MIT license. You pay only for your own Claude Code or Codex usage.
